Privacy policy

rclone backups is a private tool run by Pinakeshwar Dighe. It is not offered to the public.

  • It only accesses files and folders in Google Drive that it created itself (drive.file permission).
  • It uploads encrypted backup files and deletes old backup files it created. It does not read any other Drive content.
  • No Google user data is shared with, sold to, or sent to anyone else.
  • Access can be removed at any time from Google Account, Security, Third-party connections.
